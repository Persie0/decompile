# Pixel Camera 8.8.225 decompilation

This directory tracks the source-only JADX decompilation of the Pixel Camera APK attached to the `pho` release.

Input:

- package: `com.google.android.GoogleCamera`
- version: `8.8.225.510547499.09`
- version code: `66251366`
- APK SHA-256: `9ca2264cbf5680c8b5b740e53849c1586c53436a7e860616584c0349dba37c47`

The decompilation is produced with JADX 1.5.6 using automatic deobfuscation and the same source-only approach used for the LingQ archives. R8/ProGuard identifiers that were removed at build time cannot be recovered without Google's original mapping file.

To avoid storing a large generated archive directly on the main branch, the split persistent archive is generated by the public `Persie0/Playground` workflow and stored on its `gcam-decompiled` branch. Reconstruct and verify it with:

```sh
python3 tools/reassemble_google_camera.py
```

The script downloads the manifest and all split parts, rebuilds `google-camera-8.8.225.510547499.09-jadx-sources.zip`, and verifies its size and SHA-256 before accepting it.

Note: decompiled output is approximate source reconstruction, not Google's original source tree.
